# Random Quote Generator

A responsive Random Quote Generator built using HTML, CSS, and JavaScript as a CodeAlpha internship project.

## Features
- Displays a random inspirational quote.
- Generates a new quote when the New Quote button is clicked.
- Copies the displayed quote using the Copy Quote button.
- Clean, responsive design.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Click New Quote to display another quote.

## Project Purpose
This project demonstrates basic web development skills, including webpage structure, styling, JavaScript event handling, and clipboard functionality.
